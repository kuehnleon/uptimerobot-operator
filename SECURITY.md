# Security Policy

## Supported versions

Security fixes are made for the latest release line. Upgrade to the latest patch release before reporting a vulnerability.

| Version | Supported |
| --- | --- |
| `v0.2.x` | Yes |
| Older versions | No; upgrade to the latest release |

## Reporting a vulnerability

Please report vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/kuehnleon/uptimerobot-operator/security/advisories/new). Do not report security issues in public issues or pull requests.

Include the affected version, impact, and steps to reproduce. Avoid including live API keys or other credentials; redact them from logs and proof-of-concept material.

Maintainers will acknowledge reports as soon as practical and coordinate investigation, remediation, and disclosure with the reporter.
